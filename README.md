# AI Workplace Hub

Build the requested modern responsive SaaS web app, “AI Workplace Productivity Assistant.” Follow the full specification: no authentication, no user database or persistence, direct Dashboard entry; persistent responsive sidebar/header; dashboard plus Smart Email Generator, Meeting Notes Summarizer, and AI Chatbot pages; cream/silver/orange professional visual system. Enable Lovable Cloud and Lovable AI as needed solely for secure per-request real AI generation, with no storage of user content. Every generated output must be dynamic from the structured prompts provided by the user, editable, have loading/empty states and the specified consistent AI disclaimer. Include Responsible AI modal with the exact supplied guidance. Ensure mobile/tablet responsive layouts and session-only counters/activity.
